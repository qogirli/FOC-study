## 当前边界

- `Core/Src/main.c` 中 `CURRENT_SAMPLING_ONLY = 1`。
- 仅启动 TIM8 CH4 作为 ADC 硬件触发源，不启动 CH1~3 和 CH4 中断，不处理按键启动请求。
- PH9（代码名 MOTOR_EN，高电平使能）保持低电平，关闭驱动；回调入口也禁止进入使能逻辑。
- ADC1 注入 IN6、ADC2 注入 IN8；普通组不启动，不使用 DMA。回调分别保存两路原始值与采样次数。
- 上电后每路丢弃 2000 次数据，再平均 256 次得到零点，ready 仅代表平均完成。采样电路须正常供电、电机无电流；供电较晚时复位重测。尚未换算安培或接入电流 PI。

## 编码器观察（新增）

- TIM2 编码器接口，PA15=A 相（TIM2_CH1），PB3=B 相（TIM2_CH2），A、B 两路都计上升沿和下降沿（4 倍频）。接线已由使用者确认，主板为 2025 版。
- 初始化由 CubeMX 生成：在 IOC 里加了 TIM2 的编码器模式（TI1 和 TI2 都计数，输入滤波 6），`tim.c`、`tim.h` 是生成结果。以后新增外设一律先改 IOC 再生成。
- 编码器 1000 线，4 倍频后机械一圈 4000 个计数。
- 串口新增一行 `enc_cnt=… enc_delta=…`，每 100ms 一次。只观察，不参与 FOC 计算，也不改变 PWM。
- 用法：电机不上电，手转电机轴，看计数是否随转动增减，正转、反转符号是否相反，转一圈是否约差 4000。
- PA15、PB3 默认是 JTAG 引脚，当前用 SWD（PA13、PA14）调试，不受影响。

## 编码器电角度、对零、编码器换相（新增）

- 电角度 = (计数 - 对零时的计数) 对 1000 取余，再按 360° 折算，一个电周期 1000 个计数（1000 线 4 倍频一圈 4000 个计数，极对数 4）。
- 对零：KEY2 或串口发 `a`。电压矢量固定在 0°、1V，保持 2 秒，让转子停在 d 轴；最后 300ms 计数变化不超过 5 才算成功，串口打印 `align ok=1 zero=… drift=…`。
- 编码器换相：KEY3 或串口发 `v`，必须先对零成功。电压矢量始终超前转子 90°（只有 Uq，1V），最长 5 秒自动停；每个 PWM 周期计数变化超过 12（约 3600rpm）立即停机。
- 停止：KEY1 或串口发 `x`，对零或换相中再按任意一个键也会停；`p` 检查串口，回 `pong`。
- 串口新增字段：`enc_ok`（对零是否有效）、`enc_e_mdeg`（电角度，千分之一度）、`aux`（0无 1对零 2换相）。
- 限制仍然是 1V、不提高电流限制。电流环还没有接入，这两个模式都不用电流反馈。

## 电流环、速度环、位置环（新增，已上板验证）

三环都用编码器电角度，电压矢量始终限制在 1V 内，每次最长 5 秒自动停，超速（每个 PWM 周期计数变化超过 12）立即停。都要先对零成功。串口命令（不用按键）：

| 命令 | 作用 |
| --- | --- |
| `a` | 对零 |
| `c` | 电流环；`i`/`k` 改 Id 给定，`u`/`j` 改 Iq 给定，每次 0.1A，`0` 清零 |
| `s` | 速度环；`u`/`j` 改速度给定，每次 20rpm，`0` 清零 |
| `g` | 位置环；`u`/`j` 改位置给定，每次 1000 计数（机械 90°），`0` 回到起点 |
| `e`/`d`、`r`/`f`、`t`/`y` | 速度环 Kp、速度环 Ki、位置环 Kp，每次乘或除 1.5（速度环、位置环运行中） |
| `x` | 全部停止 |

- 电流环：Clarke → Park（编码器角度）→ Id、Iq 两个 PI（Kp 0.5V/A，Ki 250）→ 逆 Park → SVPWM。电流符号实测与预期相反，所以 `CURRENT_SIGN = -1`。
- 速度环：每 1ms 一次，速度 = 5ms 内计数变化（分辨率 3rpm），PI 输出 Iq 给定（Kp 0.015A/rpm，Ki 0.3），Id 给定为 0，Iq 给定上限 1.0A。
- 位置环：位置误差乘 0.3rpm/计数得到速度给定，限幅 60rpm，再交给速度环。
- 对零改成两段：矢量先到 +90° 再回 0°，再到 -90° 再回 0°，取两次停下位置的平均。原因：静摩擦很大，只放一次 0° 矢量时，转子可能停在对面 180° 附近，速度环就变成正反馈（实测出现过一次，转子以 -150rpm 反向跑）。连续对零 3 次，零点只差 1 个计数。
- 串口新增字段：`spd_x10`（转速平均，0.1rpm）、`spd_sd_x10`（窗口内标准差）、`spd_min_x10`、`spd_max_x10`、`spd_ref_x10`、`pos_err`。

### 上板结果（空载，1V 限幅，电源电压不变）

- 电流环：Id 给 0.5A，100ms 平均 499~500mA；Iq 给 0.2A，平均 199~200mA；Id 保持 0。起转需要约 0.45~0.5A（静摩擦大），所以 Iq 上限从 0.6A 放到 1.0A（对零时用过 1.95A）。
- 速度环：Kp 0.003 时低速粘滑来回抖（60rpm 给定，窗口标准差 28rpm）；Kp 0.015 以上稳定，60rpm 给定平均 60.1rpm，100rpm 给定平均 99.9rpm（100ms 平均值的标准差 1.5rpm）；从 +60 反转到 -60rpm 约 0.5 秒，平稳过零。
- 位置环：给 +1000 计数约 0.45 秒到位，无过冲，停在 ±2 计数内（约 0.18° 机械角）；再 +1000、再 -2000 回到起点，同样 ±2 计数。
- 电流采样噪声：驱动关闭时 Id、Iq 每个采样的标准差约 0.26A、0.40A；电流环在原地闭环时标准差不变，说明环路没有把噪声变成真实电流。相同工作点（1V，约 151rpm）下，电压模式（没有电流反馈）转速窗口标准差 9.8rpm，电流环模式 10.3rpm，没有可见差别；转速抖动主要来自齿槽和摩擦。
- 结论：做有感闭环、转速、位置控制可以忽略这个噪声。不能忽略的场合：用单个采样做过流判断（会误报，要用平均或比较器）、10mA 级别的小电流精度、转矩脉动优化。
