## 当前边界

- `Core/Src/main.c` 中 `CURRENT_SAMPLING_ONLY = 1`。
- 仅启动 TIM8 CH4 作为 ADC 硬件触发源，不启动 CH1~3 和 CH4 中断，不处理按键启动请求。
- PH9（代码名 MOTOR_EN，高电平使能）保持低电平，关闭驱动；回调入口也禁止进入使能逻辑。
- ADC1 注入 IN6、ADC2 注入 IN8；普通组不启动，不使用 DMA。回调分别保存两路原始值与采样次数。
- 上电后每路丢弃 2000 次数据，再平均 256 次得到零点，ready 仅代表平均完成。采样电路须正常供电、电机无电流；供电较晚时复位重测。尚未换算安培或接入电流 PI。
- 没有复制旧编译产物。烧录前必须重新编译，不能使用旧工程的 HEX。

下一步：验证两路原始值、计数与偏置；固定 U/V 仅是静态测试，后续再按扇区切换采样相并覆盖 W 相。不要把普通组 DR 连读三次当成三相数据。

本阶段未做硬件验证。解除 CURRENT_SAMPLING_ONLY 前，先完成采样与启动时序检查。

## 编码器观察（新增）

- TIM2 编码器接口，PA15=A 相（TIM2_CH1），PB3=B 相（TIM2_CH2），A、B 两路都计上升沿和下降沿（4 倍频）。引脚依据硬石 657（EncoderPosition）参考例程，实际接线待验证。
- 串口新增一行 `enc_cnt=… enc_delta=…`，每 100ms 一次。只观察，不参与 FOC 计算，也不改变 PWM。
- 用法：电机不上电，手转电机轴，看计数是否随转动增减，正转、反转符号是否相反。一圈计数可用手转一圈的差值估计。
- 未编译烧录验证。PA15、PB3 默认是 JTAG 引脚，当前用 SWD（PA13、PA14）调试，不受影响。
