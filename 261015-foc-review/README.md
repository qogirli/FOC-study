# 精简复习工程

给复习用的最小版本：硬件配置（CubeMX 生成的 TIM8、ADC1/ADC2、TIM2 编码器）和 `260921-current-sampling` 相同，但 `main.c` 从最小开始，一站只加这一站必需的代码。完整的闭环版本（含串口调试命令）存在分支 `reference/closed-loop-full`，只用来参考。

打开 `MDK-ARM/260818-start-six-foc.uvprojx` 编译。工程名沿用旧名，避免破坏 CubeMX 和 Keil 的关联。

## 各站

| 站 | 内容 | 状态 |
|----|------|------|
| 1 | 开环：电压矢量 → SVPWM → 三个 CCR，KEY1 启停 | 已验证 |
| 2 | ADC 采样 U、V 相电流，上电零偏校准，串口打印 | 已验证（零点约 2070，开环 1 V 时电流幅值约 2.9 A） |
| 3 | Clarke、Park（先用开环角度观察 Id、Iq） | 已验证（开环 1 V：Id 约 3 A 不变，Iq 接近 0） |
| 4 | 编码器电角度、两侧对零、按转子角度运转（电压矢量在磁极前 90 度） | 已验证（约 250 rpm，Iq 约 0.45 A，Id 约 -0.15 A） |
| 5 | 电流环（Id、Iq 的 PI + 逆 Park） | 未做 |
| 6 | 速度环、位置环 | 未做 |

## 第 2 站注意

- 零偏校准在上电后立刻做，此时驱动关闭、电机没有电流。**必须先给母线（现在用 12 V）上电，再给单片机上电或复位**。母线没上电时采样电路没有中点偏置，读数在 0 附近，校准出的零点是错的。
- 串口 USART1，921600 波特，每 200 ms 一行：`cal`（校准完成）、`raw_u/raw_v`（最近一次原始读数）、`Iu_mA/Iv_mA`（这 200 ms 的平均电流）。
- 校准完成前 KEY1 不起作用。

## 第 4 站用法

- KEY1：停止时按，先对零（约 2.8 秒，电机会来回抖一下）再转起来；转动时按，停止。对零失败（两次停点差超过 120 个计数）就不会转，串口显示 `zero_ok=0`。
- 调试器里把 `key_sw` 写成 1，等于按一下 KEY1。
- 串口一行：`mode`（0 停、1 对零、2 运转）、`zero_ok`、`cnt`（编码器计数）、`ang_deg`（转子电角度）、`Id_mA`、`Iq_mA`。
- 运转时 Iq 是正的、Id 比 Iq 小很多，说明对零对了；如果 Iq 变负、电机越转越快往反方向跑，说明零点差了 180 度。
