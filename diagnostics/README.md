# 2026-09-23 零电流 ADC 对照诊断

## 结论与当前设备状态

尚未修复，也不能认定硬件完好。655 派生的静止采样对照同样出现噪声；3/84/480 周期的对照未消除波动。ADC1 改读 VREFINT（480 周期）时标准差约 1.16 码，外部 U/V 约 33–38 码。两路外部信号相关系数约 0.93–0.94，优先调查公共偏置、模拟供电、信号地及连接路径，不能单凭这些数据判定具体器件损坏。

已经通过 J-Link 恢复测试前的完整 Flash 镜像，烧录 Program & Verify 成功；PH9 ODR=0，TIM8 CCER=0x1000，仅 CH4 开启。没有修改学习工程源文件，没有启动电机。用户原有 uvprojx 修改保留。

## 对照方法与限制

- 原始教程 655 的 main 在延时 500 ms 后调用 MC_StartMotor1，禁止直接烧录原版用于本次静止测试。
- 本地 `655-adc-zero` 是完整例程副本，保留其时钟、GPIO、ADC/TIM 初始化；替换 main 控制流程和 SysTick，禁止 MC 初始化/启动，PH9 输出低，CH1–3 不启动。
- 不声称运行了完整原版 FOC：去掉 TIM2 从触发等待，以 CH4 独立运行；固定 ADC1/IN6、ADC2/IN8 单注入秩；轮询 JEOC 保存原始数据而不是原例程电流环中断。无 DMA、无平均滤波。
- 丢弃前 2000 次，板内缓存每路 4096 点，缓存完成后读取。快轮询旨在逐触发读取，但没有硬件丢样计数，因此不把数组视为经严格验证无丢点的连续时间记录。
- 655 定时器 ARR=4666，对应约 18 kHz，不是学习工程 20 kHz；本次比较零电流噪声，尚未作运行电机有效窗口验证。
- 左对齐注入结果按 RM0090 13.4 右移 3 位还原 12 位数；学习工程是右对齐，无需此步骤。参考：https://www.st.com/resource/en/reference_manual/dm00031020-stm32f405-407-415-417-437-455-469-application-note-stmicroelectronics.pdf
- 3/84/480 周期分别为采样寄存器编码 0/4/7。VREFINT 始终使用 480 周期，并开启 TSVREFE。
