## 当前测试边界

- 用户电源设定：18 V、0.8 A 限流，不擅自提高。
- 无感 FOC 仍使用相电流反馈和电机模型，不是绕开当前 ADC 波动的方法。
- 652 默认目标 1000 rpm，观测器最低切入转速 500 rpm；启动阶段不是之前 1 V / 1 Hz 开环慢转。
- PDF 第 11 页无感接线还包括 W 电流 PB1、母线 PC0、温度 PC3，不能只沿用已经观测到的 U/V 两路便认为全部输入已验收。
- PDF 是旧板 SD 不接的接线说明；当前板 PH9 的使能逻辑已在前序实测中使用。不能用旧文档覆盖当前板已确认的 PH9 行为。
- 本轮仅完成资料核对，未烧录无感固件、未启动电机。当前学习工程和原始资料未修改。
