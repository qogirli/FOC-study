# 652 无感 FOC 限时验证 — 2026-09-28

## 结论

**在当前硬件与 18 V / 0.8 A 电源限流条件下，本次单次短时测试成功从强拖进入无感闭环。**
这不是长期稳定性或采样精度合格认证，也没有证明电流毛刺已经解决。

| 验收项 | 实测结果 |
|---|---|
| 进入无感 RUN | 启动后 1730 ms 首次记录 RUN=6 |
| 连续保持 | 到 5000 ms 限时停止，约 3.27 s，无故障记录 |
| 观测器可靠标志 | 所有 RUN 记录为 1 |
| 3000～4990 ms 估算机械速度 | 平均 994.83 rpm；瞬时记录 858～1098 rpm |
| 同窗口霍尔独立旁证 | 1001.26 rpm（4 极对，每机械圈 24 个边沿） |
| 母线与温度 | 全部记录 16～18 V（整数接口）；温度 29℃ |
| 停机 | 5 s 撤 PH9；5010 ms 记录 STOP；5410 ms 回 IDLE |
| 恢复 | 当前 Flash 的完整 1 MiB 备份与恢复读回逐字节一致 |
| 恢复后串口 | 18 s / 170 行均 req=0、en=0、cal=1，pairs=2120/2121 |

霍尔仅在诊断代码中以 1 ms 间隔读取 PH10～PH12 并计数，没有给 652 控制器提供角度。
该计数是独立速度旁证，不是精密速度计；没有实现完整霍尔跳变顺序校验。
源码 `Src/mc_tasks.c` 的 START_RUN 分支将速度反馈从 VirtualSpeedSensor 切换为 STO_PLL，随后进入 RUN；因此不能将此结果混同为仅强拖转动。

## 静止输入核验

在电机库初始化前、PH9 关闭时，使用 ADC1 顺次各采集 256 个原始样本；随后重新初始化 ADC1，恢复原版配置再初始化电机库。
这只是输入核验，不替代原版启动零点校准，也不把预检平均值强塞入控制环。

| 输入 | ADC 平均 | 最小 | 最大 |
|---|---:|---:|---:|
| U / PA6 | 2074 | 1886 | 2176 |
| V / PB0 | 2068 | 1845 | 2160 |
| W / PB1 | 2051 | 1840 | 2173 |
| 母线 / PC0 | 1045 | 980 | 1403 |

母线按原版 0.0463 分压、名义 3.3 V 参考换算约 18.2 V。存在噪声尖峰，但三相零点均处于中点附近；初始化后的原版状态机 IDLE、当前及历史故障为零。

## 未解决的问题与结论边界

1. **噪声仍在。** 3～5 s 窗口 dq 反馈也有尖峰：iq 原始值 -2398～10467，id -8056～3650。不能用平均值漂亮来宣布采样合格；这些反馈尖峰不能未经独立测量就当成真实相电流峰值。
2. **现有毛刺不等于 FOC 必然完全跑不了。** 本次完整闭环确实成功运行；但只验证了该参数、该供电、该负载条件下的一次短运行，未作长期、堵转、反转、负载变化或重复启动验证。
3. 不能从一次实验断言之前主学习工程唯一问题在哪；652 使用完整的采样调度、校准、PI 和观测器，与手写程序的差异不止一处。
4. 本地接线 PDF 与参数 XML 的相电阻存在 0.89 Ω / 0.65 Ω 差异；本次保留 652 的 0.65 Ω，未偷偷调参掩盖差异。电机资料核对在 `../motor-reference/README.md`。
5. 串口 pairs 恢复正常不等于噪声已经消除。恢复后的原工程仍有电流读数毛刺。

学习主线建议：保留此独立例程作为已验证基线，继续霍尔角度 + 电流环逐段验证；不要把手写工程一口气换成无感观测器。无感验证已回答“硬件是不是完全做不了 FOC”，但不会替代电流采样质量排查。
